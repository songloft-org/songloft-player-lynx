## Behavior and limits

- Web already hides and retains plugin workers, while native frames belonged to routed pages and were destroyed on library navigation. Native main-navigation plugins now belong to the Shell and retain the same frame after first use, preserving search, results, selection, settings drafts and scrolling pages. Pushed pages and Web retain their existing paths.
- Hidden native pages receive `lifecycle: paused`; selected pages receive `resumed`. App foreground events are not forwarded to hidden frames. Bili pauses UI polling for downloads, monitoring and QR login while hidden, and refreshes on return. Theme/player channels remain available.
- Retention is local to the current Shell/login session and is not stored on the server. Server scope changes reset the container; plugin version/update identity changes reset frames; disabled/uninstalled plugins are removed. Leaving the Shell or signing out cleans up. Persistence across app restart or the full-player route is not promised.
- Bili separates expanded-part visibility from fetched parts, allowing collapse and reopening without another request. Titles explicitly clamp to two lines with wrapping/ellipsis and reserve space for selection, cover and actions.
- Import playlists, monitored favorites and monitoring target playlists use a cancellable searchable picker with at most 20 rows per page. Closed fields show only the current choice. Search covers the whole collection, including empty results and page boundaries. Input changes are no longer redundantly echoed into native controls, avoiding search-input races.
- Web also had a host race: an optional `enableEvent` call silently dropped bindings arriving before custom-element upgrade, leaving visible typed text with a disabled search button. Both development and production patches for the pinned web-core now queue handler counts, replay after definition, and account for intervening removals. The lockfile changes only the patch hash. HTML fallback deployment also requires refreshed server-side `web-core/` assets.
