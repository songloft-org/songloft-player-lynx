## Failures found by actual builds

1. **Mixed Node-API ABIs:** full app crashed at zero on Lynx_JS while reporting `lynx_napi_report_and_clear_exception`. Separate weak/strong C APIs were insufficient: `NAPI_CPP_CUSTOM_NAMESPACE` must isolate inline C++ wrappers. The fix restores real login and storage/network/keyboard RPC. Screenshot: `/tmp/songloft-desktop-business-arm64.jpeg`; original `.ips` remains on Mac.
2. **Missing Go replacement:** git archive omits the `pkg/tag` gitlink, breaking resource builds. Packaging now archives its exact pinned commit; CI initializes only that required module and metadata records its SHA.
3. **Packaging scope/downloader:** stage the business bundle inside desktop; exclude downloaded development runtimes. Use pinned official builder patches with pnpm. app-builder-lib 26.13.0 needs CacheMode absent from `@electron/get` 3.0.0; pinning 3.1.0 restores DMG/ZIP generation.
4. **AppleDouble in signed ZIPs:** generic Go extraction materialized `._*` metadata as extra files and strict codesign failed. After bounded path checks the helper ignores AppleDouble/`__MACOSX`, retaining traversal/link checks. Signed fixture and full-ZIP verification are separate runs.
5. **Windows paths:** follow the [NSIS parameter contract](https://nsis.sourceforge.io/Docs/Chapter3.html#3.2.1): direct CreateProcess command line with final unquoted `/D=`, including spaces, without a shell. Actual Windows installation is Not run.
6. **Framework links/input state:** canonicalize macOS `/var`/`/tmp` aliases before validating resolved links; the complete CEF ZIP now extracts with strict codesign verification passing. `NSTextInputClient` alone does not mean active editing: the pinned embedder active-flag check passes an actual AppKit regression. IME/shortcut device acceptance remains open.
7. **Locking/source identity:** combined screen/window state controls presentation and plugin polling while the same engine retains audio. Source changes block publication of a build identity, demonstrated by `/tmp/songloft-desktop-source-change-rejected.log`; rebuilding stable source passes.
8. **Migration confirmation after a remote launch:** review found that an update first launched into remote mode did not run the local database migration, and the old confirmation path was never called if the user switched to local later. The new app is now confirmed only after the local backend health check succeeds, and a later local startup migration failure offers recovery of the previous app with its matching database backup. This branch still needs real upgrade acceptance.
9. **Parent-exit startup race:** Go begins watching the parent pipe before app initialization. A new readiness callback fires after `http.Server` registers its listener and enters `Accept`, so parent exit during initialization or bind cannot close the database before the server is created and then leave it listening. The source is gofmt-formatted; Go tests and cross-platform builds were not run this turn and remain for final acceptance.
10. **Lynx child-frame bridge timing:** if the child runtime becomes ready before the host registers its frame identity, the bridge extension now looks up the bound identity on the child's first call. This avoids permanently rejecting child calls with an empty identity. The source is clang-formatted; the native extension was not built and plugin writes were not exercised this turn.
11. **Update directory creation failure:** the download path created its directory before entering its cleanup block, so a permission or disk error could leave the state at `downloading` with an active timeout. Directory creation now uses the same error, cancellation and cleanup path, allowing the failure to be reported and retried. Updater checks were not run this turn.
12. **Failure to write the post-install startup record:** if the record could not be written after replacing the app, the new version had not started and the old app remained at `.previous`. The helper now syncs a same-directory temporary record and publishes it atomically; a write failure restores and restarts the old app instead of leaving an untracked replacement. Updater checks and cross-platform installation remain Not run.
13. **Cancel host uploads on session changes:** server switches and Bundle crashes cancelled shared network, cache and plugin tasks, but file-picker uploads have their own AbortController and could continue against the old session. Local/remote transitions and unexpected Bundle exits now stop platform tasks too. Runtime checks were not run this turn.
