## Investigation and changes

The reporter still sees the issue on iOS 18.6 Safari, server v2.13.7 and client 0.1.7. The earlier native delegate fix `1d9317a` is in 0.1.7 history but does not cover browser uploads. Web business code runs in a Worker, then an RPC clicks a hidden input on the main thread. When opening the picker is blocked, neither change nor cancel settles the upload Promise.

Web uploads now share a visible file panel in `web/file-transfer-host.js`. Clicking the actual file control establishes a main-thread gesture. URLs, multipart fields and same-origin cookies are preserved. ZIP selection accepts extension and MIME hints. Cancel, HTTP/network errors and a four-minute upload deadline settle the operation and clean up controls, timers and transport. Picking a file has no deadline. The DOM fallback uses the same host. Text-only cancellation cannot cancel uploads. Native ABI is unchanged.

This is a reproduced Web defect, not proof that it is the reporter's only device issue. User activation reference: [WebKit](https://webkit.org/blog/13862/the-user-activation-api/).

Full-page acceptance also confirmed a shared client contract bug: it sent the multipart field `plugin`, while Swagger and `internal/handlers/jsplugin.go` require `file`. The real server returned 400. The shared call now sends `file`, fixing local plugin uploads on Web and native clients without changing the server API. The new page regression fails with the old field: `/tmp/songloft-545-field-before.log`.
