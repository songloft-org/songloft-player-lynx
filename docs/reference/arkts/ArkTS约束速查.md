# ArkTS 约束速查（AI 优化版）

> 本文档为 AI 高效使用版，省略示例代码，仅保留规则要点。完整示例见原文档。

## 核心原则

1. **静态类型优先**：禁用 `any`/`unknown`，必须显式类型
2. **对象布局编译时确定**：运行时不可增删属性/方法
3. **不支持 structural typing**：类型兼容需继承/implements/类型别名
4. **运算符语义受限**：一元 `+`/`-`/`~` 仅用于数值

## 部分支持特性

| 特性 | 限制 |
|------|------|
| 展开运算符 `...` | 仅数组/TypedArray，仅用于剩余参数/数组复制 |
| 泛型类型推断 | 仅从参数推断，不从返回值推断 |
| 函数返回类型省略 | 若 return 调用未标注返回类型的函数则报错 |
| Utility Types | 仅 `Partial`/`Required`/`Readonly`/`Record` |
| 标准库 | 禁用 `eval`、Object/Reflect/Proxy 动态方法 |
| ESObject | 仅局部变量，仅跨语言调用赋值（API18 后放宽） |

---

## 强制规则

1. **类型/命名空间名唯一**：不与变量/函数重名
2. **对象字面量需类型标注**：不可初始化 `any`/`Object`/带方法类/readonly 类/含参构造类
3. **数组字面量元素可推断**：否则显式标注
4. **类型转换仅 `as T`**：禁用 `<T>` 语法
5. **接口不能继承同名方法的两个接口**
6. **枚举成员同类型编译时常量**：禁用运行时表达式
7. **命名空间仅声明**：非声明语句放函数中
8. **严格类型检查强制开启**：`noImplicitReturns`/`strictFunctionTypes`/`strictNullChecks`/`strictPropertyInitialization`
9. **.ts/.js 不可 import .ets**

## 常见重构模式

| 场景 | TS 写法 | ArkTS 写法 |
|------|---------|------------|
| 动态键值 | `obj['key']` | `Map<K,V>` |
| 类型合并 | `A & B` | `interface C extends A, B {}` |
| 可选删除 | `delete obj.x` | `obj.x = null` |
| 函数内函数 | `function inner(){}` | `let inner = () => {}` |
| 类型守卫 | `arg is Foo` | `arg instanceof Foo` + `as Foo` |
| 解构 | `let {a,b} = obj` | `let a=obj.a; let b=obj.b` |
| 展开对象 | `{...obj, z:3}` | 构造函数传参 |
